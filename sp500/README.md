### 검증
tickericons가 페이지에 표기한 자체 총계는 **1976년 이후 402건 변경 / 편입 383 / 편출 379**다.
위 파싱 결과(2006~2026년) 382건 / 363 / 360과 비교하면 1976~2005년 30년치가 20건 / 20 / 19에
해당한다. 즉 **파싱이 tickericons 데이터의 2006~2026 구간을 사실상 전부 담고 있다.**

### 두 집계가 다른 이유
- **2011~2018년은 거의 일치**한다(커버율 96~104%). 이 구간은 tickericons가 실질적으로 전수다.
- **2006~2010년은 크게 모자란다**(커버율 3~79%). 2006년은 1건만 수록되어 있다(6월 2일
  Juniper Networks ← Albertsons). 실제로는 32건이다. tickericons의 오래된 데이터가 성긴 것이다.
- **2019~2026년은 77~90%**다. 차이의 대부분은 티커 변경(사명 변경)이다. tickericons는 티커
  변경을 별도 행으로 잡기도 하고(2019년 FOXA/FOX, 2023년 EG←RE, 2017년 BKR←BHI 등) 안 잡기도
  한다. 구성종목 diff는 전부 편입 1 + 편출 1로 잡는다.
- tickericons에는 편입만 있고 편출이 없는 행(스핀오프)과 그 반대(피인수)가 따로 있어
  편입 수 ≠ 편출 수인 해가 있다(2015, 2016, 2014, 2022 등).

## 왜 보도자료 건수 < 편입 건수인가 (2024년 예시)

2024년 편입 20건의 내역:

| 적용일 | 편입 | 편출 | 유형 |
|---|---|---|---|
| 02-01 | DAY | CDAY | 티커 변경 (보도자료 없음) |
| 03-04 | DOC | PEAK | 티커 변경 (보도자료 없음) |
| 03-18 | DECK, SMCI | WHR, ZION | Q1 정기 |
| 03-25 | CPAY | FLT | 티커 변경 (보도자료 없음) |
| 04-01 | SOLV | VFC | 수시 |
| 04-02 | GEV | XRAY | 수시 |
| 05-08 | VST | PXD | 수시 |
| 06-24 | CRWD, GDDY, KKR | CMA, ILMN, RHI | Q2 정기 |
| 07-08 | SW | WRK | 수시 (보도자료 미확보) |
| 09-23 | DELL, ERIE, PLTR | AAL, BIO, ETSY | Q3 정기 |
| 09-30 / 10-01 | AMTM | BBWI | 수시 |
| 11-26 | TPL | MRO | 수시 |
| 12-23 | APO, LII, WDAY | AMTM, CTLT, QRVO | Q4 정기 + 수시 |

합계 편입 20 / 편출 20.

건수와 보도자료 수가 어긋나는 이유는 세 가지다.

1. **티커 변경은 보도자료가 발행되지 않는다.** 2024년엔 3건(CDAY→DAY, PEAK→DOC,
   FLT→CPAY). 데이터셋에서는 편입 1 + 편출 1로 잡히지만 실제 기업 교체가 아니다.
2. **하나의 보도자료가 여러 종목을 담는다.** 정기 리밸런스 보도자료 1건에 2~4종목이
   들어간다.
3. **수시 교체 보도자료를 전부 확보하지 못했다.** 검색으로만 수집했기 때문.

따라서 `press_releases_2012_2026.csv`의 행 수는 종목 수가 아니라 **보도자료 건수**이며,
`annual_change_counts_2006_2026.csv`의 건수와 직접 비교하면 안 된다.

## 출처와 한계 — 반드시 읽을 것

### 건수의 출처
위 건수는 **S&P 공식 집계가 아니다.** S&P 500 구성종목 이력 데이터셋
([fja05680/sp500](https://github.com/fja05680/sp500)의 `S&P 500 Historical Components &
Changes (Updated).csv`, 1996-01-02 ~ 2026-06-30, 2,718행)의 날짜별 티커 리스트를
인접 행끼리 diff 해서 센 값이다. 해당 데이터셋의 원 출처는 Andreas Clenow의
『Trading Evolved』 부속 데이터(1996–2019) + 이후 위키피디아 "List of S&P 500 companies"
변경 이력 수동 갱신이다.

**티커 변경(사명 변경)이 편입 1 + 편출 1로 중복 집계되어 있다.** 최근 연도 기준 연 2~4건.
예: 2024년 CDAY→DAY, PEAK→DOC, FLT→CPAY / 2025년 PARA→PSKY, FI→FISV /
2026년 MMC→MRSH, SATS→ECHO. "실제 기업 교체" 기준으로는 그만큼 빼야 한다.
2025년의 경우 공식 보도자료로 확인한 실질 건수는 편입·편출 각 19건이다(표의 21건 대비).

### 공식 연도별 집계는 여기에 있다 (미확보)
S&P Dow Jones Indices가 직접 집계한 1995–2021년 편입·편출 전수 데이터:
- <https://www.spglobal.com/spdji/en/research/article/what-happened-to-the-index-effect-a-look-at-three-decades-of-sp-500-adds-and-drops/>
- PDF: <https://www.spglobal.com/spdji/en/documents/research/research-what-happened-to-the-index-effect.pdf>

이 문서를 확보하면 위 표의 2006–2021 구간을 공식 수치로 교체할 수 있다.

### 보도자료 링크의 한계
- **2006–2011년: 링크 없음.** press.spglobal.com 아카이브에 수록되어 있지 않다.
  검색으로 확인된 가장 오래된 건이 2012-02-09.
- **2012–2019년: 전건이 아님.** 연간 20건 안팎 중 3~7건만 수록. 아카이브
  페이지네이션(`press.spglobal.com/index.php?s=2429&o=N`)을 직접 열지 못해
  검색으로 잡힌 것만 모았다.
- **2020–2026년: 사실상 전건.**
- 티커 변경은 보도자료가 발행되지 않으므로 링크가 존재하지 않는다.

## 재현

```bash
curl -sSL -o sp500_hist.csv \
  "https://raw.githubusercontent.com/fja05680/sp500/master/S%26P%20500%20Historical%20Components%20%26%20Changes%20(Updated).csv"
python3 - <<'PY'
import csv, collections
rows = [(r['date'], set(t for t in r['tickers'].split(',') if t))
        for r in csv.DictReader(open('sp500_hist.csv'))]
add, rem = collections.Counter(), collections.Counter()
for (_, s0), (d1, s1) in zip(rows, rows[1:]):
    y = int(d1[:4]); add[y] += len(s1 - s0); rem[y] += len(s0 - s1)
for y in range(2006, 2027):
    print(y, add[y], rem[y])
PY
```
