# 왜 사이트마다 숫자가 다른가

S&P 500 "연간 편입 건수"에는 **업계 표준 정의가 없다.** 아래 7가지를 어떻게 처리하느냐에
따라 같은 해가 16건도 되고 20건도 된다. 데이터가 틀린 게 아니라 세는 대상이 다르다.

## 2024년을 예로 — 전부 맞는 숫자 4개

| 정의 | 2024년 편입 | 출처 |
|---|---:|---|
| 지수 구성 리스트에서 티커가 새로 나타난 횟수 | **20** | 구성종목 diff |
| 위에서 티커 변경 3건 제외 | **17** | diff − 사명변경 |
| "기업 교체 이벤트" | **16** | tickericons.com |
| S&P 공식 보도자료 건수 | **9** | press.spglobal.com |

같은 해, 같은 사실, 네 개의 다른 답. 전부 맞다.

## 차이를 만드는 7가지

### 1. 티커·사명 변경
2024년 `CDAY→DAY`(Ceridian→Dayforce), `PEAK→DOC`(Healthpeak), `FLT→CPAY`(FleetCor→Corpay).
구성종목 리스트로는 편입 1 + 편출 1이지만 기업은 그대로다. S&P는 보도자료를 내지 않는다.
- **세면** 연 +2~4건. **안 세면** 0건.

### 2. 복수 주식클래스
2015년 9월 S&P가 복수 클래스 종목 처리 방법론을 바꾸면서 클래스 주식이 개별 편입됐다.

```
2015-09-21  IN CMCSK, FOX, NWS   OUT 없음     ← 편출 없는 편입 3건
2016-01-04  IN CCEP, CPRI        OUT 없음
2016-04-08  IN UA (C클래스)       OUT 없음
2015-12-14  IN 없음               OUT CMCSK    ← 다시 제거
```

2015년(30건)·2016년(31건)이 유독 높은 게 이 때문이다. 새 기업이 들어온 게 아니다.

### 3. 스핀오프 = 편입만, 편출 없음
```
2024-09-30 AMTM(Amentum)   2025-10-30 SOLS(Solstice)   2025-11-03 Q(Qnity)
2026-06-01 FDXF(FedEx Freight)   2026-06-29 HONA(Honeywell Aerospace)
```
모기업은 지수에 남아 있고 신규 종목만 늘어난다.

### 4. 피인수 = 편출만, 편입 없음
```
2024-10-01 BBWI   2025-10-31 KMX   2025-11-04 EMN   2026-06-02 EPAM   2026-06-30 CAG
```
그래서 **편입 수 ≠ 편출 수인 해가 생긴다** (2014, 2015, 2016, 2022 등).

### 5. 스핀오프·피인수가 하루씩 어긋남
```
2024-09-30 AMTM 편입
2024-10-01 BBWI 편출     ← 실질은 "AMTM이 BBWI 대체" 1건
```
날짜 기준으로 세면 2건, 이벤트 기준으로 세면 1건.

### 6. 발표일 vs 적용일
2025-12-05 발표 → 2025-12-22 적용. 연말 건은 어느 날짜를 쓰냐에 따라 연도가 갈린다.

### 7. 데이터 커버리지
오래된 연도는 출처 자체가 결측이다. tickericons는 2006년에 1건만 수록돼 있다
(실제 32건). 이건 정의 문제가 아니라 데이터 부재다.

## 그래서 어떻게 써야 하나

**숫자만 쓰지 말고 정의를 한 줄 붙인다.** 그러면 어떤 숫자든 방어된다.

> S&P 500 연간 편입 건수(지수 구성종목 리스트 기준, 티커 변경 포함): 2024년 20건

> S&P 500 연간 기업 교체 건수(티커 변경·주식클래스 조정 제외): 2024년 16건

**용도별 권장**

| 목적 | 정의 | 이 저장소 파일 |
|---|---|---|
| 인덱스펀드 회전율·거래비용 | 리스트 변동 전부 | `annual_change_counts_2006_2026.csv` |
| "몇 개 기업이 갈렸나" | 기업 교체만 | `tickericons_counts.csv` (2011년 이후) |
| 개별 사건 근거 제시 | S&P 공식 보도자료 | `press_releases_2012_2026.csv` |
| 2006~2010년 | 리스트 변동만 가능 | `annual_change_counts_2006_2026.csv` + `SOURCES.md` |

**한 출처로 통일할 것.** 연도마다 다른 출처를 섞으면 추세가 왜곡된다. 2015~2016년이
튀어 보이는 것도 실제로는 주식클래스 방법론 변경 탓이지 시장 변화가 아니다.
